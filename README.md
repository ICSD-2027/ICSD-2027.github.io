# ICSD 2027 website

Static conference website prepared from the HTML files already in this directory. Open `index.html` in a browser to preview it. No build step or package installation is required.

## Edit content

- Each page is a standalone HTML file. Edit the relevant page, then check it in a desktop and mobile browser.
- Shared visual styles live in `style.css`. The AMSS logo is in `images/amss-logo.png`.
- Navigation and footer links appear in each page. If you add or rename a page, update those links on every page.
- `participants.html` is retained as a redirect to `committees.html` for existing links.

## Review before publication

The original local files supplied the conference title, Beijing, 19–25 June 2027 dates, AMSS host reference, tutorial lecturer names and committee roster. These details are displayed as draft information and need organizer confirmation. The venue, contact email, detailed themes and call, submission deadlines, program, registration details and travel guidance need approved text or links. Remove the draft banner from each page only after review.

## Publish with GitHub Pages

1. The local `origin` remote points to `https://github.com/ICSD-2027/ICSD-2027.github.io.git`. The GitHub repository has not been confirmed or created through this workspace. No files have been pushed.
2. Once the repository exists and the conference details are approved, push the local `main` branch. Keep `index.html` at the repository root.
3. In the repository settings, open **Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Give collaborators repository access in the organization with a suitable role. They can update page files through pull requests and review changes before merging.

Do not publish until the draft details and placeholders have been reviewed.
