# ICSD 2027 website

This is the static website for the International Conference on Stochastic Dynamics. The public site is https://icsd-2027.github.io/ and the repository is https://github.com/ICSD-2027/ICSD-2027.github.io.

The site uses plain HTML and CSS. `index.html` is the welcome page. The six navigation pages are `index.html`, `committees.html`, `speakers.html`, `registration.html`, `program.html`, and `travel-info.html`. Shared styling is in `style.css`; the AMSS logo is in `images/amss-logo.png`. `participants.html` redirects to `committees.html` for old links.

Edit the relevant HTML page, review the change, and merge it into `main`. GitHub Pages serves the repository root, so a build step is not needed. The dates, affiliations and other conference details came from the original local files and should be confirmed by the organizers before relying on them. Registration and travel pages currently have no content.
